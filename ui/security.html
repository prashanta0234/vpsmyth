How it works

  • When the whitelist is empty, anyone can reach the panel (authentication still required).
  • Once you add an entry, only listed IPs can reach the panel — everyone else gets a 403 from Nginx before any login prompt.
  • Changes apply immediately — Nginx is reloaded after every add or delete.
  • CIDR notation is supported (e.g. 192.168.1.0/24 for a whole subnet).
  • Loopback (127.0.0.1) is always allowed so the server itself stays functional.
